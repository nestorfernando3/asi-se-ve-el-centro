(el sitio se arma con `scripts/build-site.sh`) y pueden tener rutas rotas.

- `asi-se-ve-el-centro-hero.html` — v1: anillos de texto y globo de alambre.
- `asi-se-ve-el-centro-cinematic.html` — v2: bucle cinematográfico de 12 s, solo CSS.
- `asi-se-ve-el-centro-hover-map-v2.html` — v3: mapa con pines y video al pasar el cursor; fue la base de `index.html`.
- `asi-se-ve-el-centro-atlas-hover.html` — v4: comparación de varias ciudades.
- `frames/`, `skills/` — marcos de dispositivo y skill de Open Design usados para generar v1 a v4.
- `proof/` — concept board provisional generado con IA para el primer dossier; reemplazado por fotogramas propios.
